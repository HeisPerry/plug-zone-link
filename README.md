# PLUGZONE MARKETPLACE

A full-stack peer-to-peer marketplace platform for digital services and products. Built with React, TypeScript, Tailwind CSS, and Supabase.

---

TypeScript | React | Tailwind CSS | Supabase

---

## What is PlugZone?

PlugZone Marketplace is a digital-first peer-to-peer marketplace platform where users can post and sell digital products and services, receive orders, communicate via direct messaging, build social connections, earn rewards through daily login streaks, and purchase data and airtime bundles.

---

## Key Features

### Core Marketplace
- Ad management with image uploads
- Digital-focused categories including Gaming, VPNs & Proxies, Social Media, Subscriptions, Freelancing, Courses, Verification Services, and Websites/Templates
- Complete order lifecycle from pending to accepted to completed
- Price negotiation system

### Social Features
- Friend system with requests and accept/decline
- One-way follow system to stay updated on sellers
- Real-time messaging with Supabase Realtime
- Public user profiles with stats and reviews

### Engagement & Rewards
- Daily check-in with streak tracking and milestones
- Affiliate program with unique referral links and conversion tracking
- In-app notifications for messages, orders, friend requests, and more
- Browser push notifications for re-engagement

### Trust & Safety
- Seller ratings and reviews with 1-5 star system
- Top Rated badge for high-rated sellers
- Report system for inappropriate content
- Duplicate ad detection to prevent spam

### Additional Features
- Data and airtime purchases for Nigerian networks
- Mobile-first responsive design
- Real-time updates and subscriptions

## Tech Stack

### Frontend
- React 18+ with TypeScript
- React Router for navigation
- TanStack Query for data fetching and caching
- Zustand for global state management
- Zod for form validation
- date-fns for date calculations
- Lucide React for icons

### Backend & Database
- Supabase for authentication, PostgreSQL database with RLS, storage, realtime subscriptions, and Edge Functions

### Styling
- Tailwind CSS
- Plus Jakarta Sans for headings
- DM Sans for body text

---

## Design Philosophy

- Clean, minimal interface with muted teal accent color (#0D9488)
- No AI-generated illustrations or stock photos
- All components built from scratch with Tailwind CSS
- Left-aligned layouts with purposeful spacing
- No gradient backgrounds or heavy shadows
